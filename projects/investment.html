01

解决什么问题

投资商机不会等待信息补齐。面对分散的材料、多专业意见和反复修改的报告，平台为项目组建专属 AI 投资团队，将信息收集、专业分析、圆桌讨论与报告修订串联起来，把项目价值、重大风险和推进条件交到决策者面前。

适用客户

有投资机会洞察和投前评审需求的企业，服务董事长、CEO、投资负责人、评审委员，以及项目团队和财税法务风险人员。

查看不同角色的使用价值＋
决策者 · 看清价值与条件
董事长、CEO、投资负责人和评审委员通过一页摘要掌握项目价值、核心风险、关键证据与未决事项。
项目团队 · 推进评审交付
围绕统一项目上下文整理材料、核查信息、组织评审与修订报告，减少重复查找和跨文档核对。
专业人员 · 协同把关
财务、税务、法务与风险人员对照专业分析开展复核，可定向质疑、要求补证并确认意见采纳范围。
02

核心业务场景

按需展开，查看方案如何落地。

01

高价值机会主动发现

这个机会为什么值得关注，下一步该验证什么？

从行业事件、企业变化、资本动态和舆情信号中筛选与企业战略、主营业务和产业布局相关的机会，帮助团队判断是否值得进一步研究。

  • 可以从投资机会、储备项目或自然语言问题出发。
  • 解释机会与企业的关联、当前值得关注的原因及尚存的不确定性。
  • 把初步判断整理成一页式材料，明确后续验证重点。

交付结果机会初判 + 价值与疑点 + 待验证事项

02

投前评审流程，关键节点由人把关

这个项目已经有部分材料，可以从尽调开始吗？

围绕项目目标组建 AI 投资团队，依次衔接立项分析、内部评审、尽调、报告生成、专家评审、修订与决策摘要；同时允许按真实需求调整路径。

  • 支持从指定节点启动、跳过不需要的环节、回补或重新执行节点。
  • 在同一项目上下文中关联材料、分析假设、专家意见与报告版本。
  • 材料缺失、数据矛盾、估值越界或重大风险出现时，交由人工判断。

交付结果可控的评审过程 + 关键节点确认 + 完整项目记录

03

多专业专家交叉质询

财务判断与法务意见存在分歧，依据分别是什么？

财务、税务、法务和风险专家 Agent 先独立研判，再由会议监督员组织圆桌讨论，围绕证据、假设和结论开展交叉质询。

  • 按独立陈述、交叉质疑、回应论证、共识收敛推进讨论。
  • 记录共识、未解决分歧、重大风险与建议条件，保留不同专业视角。
  • 用户可定向质疑专家，要求补充证据、量化边界或调整假设后重新分析。

交付结果多专业评审意见 + 共识与分歧清单 + 推进条件

04

报告生成与专家意见闭环修订

采纳这些专家意见后，报告具体改了哪里？

将项目事实、分析结果和专家意见组织成可供审阅、汇报和归档的材料。修改意见关联具体报告版本，由用户确认采纳范围并查看前后差异。

  • 生成项目立项建议书、尽调报告、可行性研究报告及一页决策摘要。
  • 关键事实和数据关联来源、时间及原文入口，区分事实、AI 推断与分析假设。
  • 修订生成新版本，保留原报告、专家意见和修改记录，支持预览、下载与归档。
  • 提供公文、日报、AI 简约等报告样式，适配正式报审、专题汇报和领导速览。

交付结果正式评审材料 + 修改差异 + 可追溯的报告版本

05

专业能力按需调用与自由组合

已有报告，只想做风险核查和专家复核。

用户可在同一项目会话中单独调用报告生成、专家评审、财务测算或风险查询，并按需要组合多个任务。

  • 上传已有材料即可生成报告，或直接针对已有报告组织专家讨论。
  • 围绕关键假设进行情景与敏感性分析，按明确对象查询专业风险。
  • 后续任务可引用已有产物；存在多个版本时由用户选择，保留各任务状态与结果。

交付结果贴合项目需求的分析路径 + 可复用的阶段成果

工作流与人工审核
管理阶段推进、暂停和回退，检查关键数据完整性，并在审核窗口等待人工确认。
数据与可复用能力
通过 MCP 按需连接外部数据、企业知识库和内部系统，将分析方法、业务规则与输出格式沉淀为 Skill。
运行与治理
Dora 承载 Agent 运行，MOSS 提供行业、市场与政策信息检索；结合权限、版本和来源记录支持复核与追溯。
