# 马晓甜 · 个人网站

纯静态网站，基于原 GitHub Pages 首页改造。发布于 https://xtm4273-sudo.github.io/ 。

## 预览与发布

运行 `node preview.cjs`，访问 http://127.0.0.1:8767/ 。发布时上传 index.html、assets/ 与 projects/，无需构建依赖。

## 首页与个人 IP

首页采用用户提供的《视频节点 2.mp4》。桌面保留原视频画质，手机使用 720p、24fps 的轻量版本。安卓微信通过视频帧渲染自动循环；旧内核使用动图兼容方式，不要求点击播放。普通浏览器保留静音视频自动循环。实现和验证见 docs/mobile-video.md。

角色设定图为 assets/ip-character-sheet.png。导航固定小头像贯穿每屏，聊天入口与联系区域使用同一角色，通过 SVG 视窗显示原图局部，未重画角色。“关于我”使用用户提供的会议讲解场景原图 assets/about-ai-scene.png（2048×1152），CSS 遮罩让边缘自然融入页面；去除真人头像和旧的小图文条，介绍文字左对齐，五项成果等距排列，手机端上下布局。样式位于 assets/about.css。

## 视觉主题与工作经历

全站默认深色，使用石墨黑背景、冷白正文、蓝色主操作和少量金色 IP 点缀；仍可在首页切换明暗主题，选择通过 portfolio-theme 保存，并在方案页沿用。共享样式在 assets/site-design.css，首屏主题脚本在 assets/theme.js。

工作经历在桌面端占一屏，左侧测试开发、右侧 AI 产品落地。两张卡片上方分别展示用户提供的《视频节点 9.mp4》和《视频节点 11.mp4》，使用原始 1280×720、24fps 文件，CSS 柔边遮罩融合背景。视频静音循环、进入可见区域加载、离屏暂停，并提供暂停按钮。手机端依次展示视频和对应卡片。

底部联系区采用左侧大幅透明 IP 人物、右侧联系信息，邮箱和微信有轻微呼吸光晕与悬停增强。微信按钮可复制号码，开启减少动态效果时停用自动动画。样式与交互位于 assets/character-sections.css/js；图片来源及生成提示记录在 docs/character-assets.md。

## 四类高价值方案展示

首页采用 A 式手风琴：桌面悬停展开，点击进入详情；手机点按展开，通过详情入口进入。方案顺序：投资平台、派单与排产、保险问数与找客户、智能客服。

四个详情页统一采用白底与浅灰底交替的分区布局：方案概览、业务问题、核心场景和实施方式。通过留白区分模块，场景可展开阅读；删除底部重复推广区块，保留固定个人 IP 头像。

投资平台、零售排班与智能客服保留用户提供的 Demo 地址，在新标签打开。金融督导改为“下载方案 PPT”，文件 assets/insurance-p7-p18.pptx 仅包含指定原文件的第 7–18 页，共 12 页，约 34 MB，保留原页内容；不再显示在线 Demo 按钮。登录凭据未写入文件，外部服务可用性未验证。

投资、保险与智能客服详情已按用户方案补充：适用角色、业务流程、可展开的场景正文与架构说明。投资含机会发现、流程控制、专家圆桌、报告修订及按需调用五个场景；金融督导含两类核心场景，智能客服含五类核心场景。方案内容使用网页摘要展示，不附原始内部文件；未将方案效果估算写成已验证成果。

## 后续补文档与链接

四个方案页均使用已确认的 A 式布局，首屏、桌面吸顶导航和手机底部提供醒目的蓝色主操作。基础样式、最终分区样式、章节导航和模板分别位于 assets/enterprise.css、assets/solution-layout.css、assets/enterprise.js、scripts/enterprise_page.py。运行 `python scripts/build_solutions.py --only investment` 可只生成投资页。

统一数据位于 content/solutions.json。修改后运行 `python scripts/build_solutions.py`，生成首页四卡片与 projects/ 下四个静态详情页。可选 document 字段维护方案正文、角色、流程、场景及架构；primary_resource 可覆盖主操作资源、按钮文案和下载文件名。

## 验证

本次检查四个详情页的桌面及 390/320px 手机布局、章节键盘展开、直接资源链接、首页卡片入口、无横向溢出及脚本错误；实际下载的 PPT 与本地文件哈希一致。PPT 包结构确认只有原第 7–18 页，保留的幻灯片 XML 与原文件一致，并完成渲染检查。未进行 Safari 真机验证。
